# Assets da marca

## Logos para o site

As três versões usam a mesma composição extraída da referência original e possuem fundo transparente real.

| Arquivo                                           | Cor                         | Uso recomendado           |
| ------------------------------------------------- | --------------------------- | ------------------------- |
| `public/images/brand/adriana-reis-logo-wine.png`  | Vinho `#762638`             | Fundos marfim e off-white |
| `public/images/brand/adriana-reis-logo-gold.png`  | Dourado champanhe `#B78A55` | Fundos vinho              |
| `public/images/brand/adriana-reis-logo-ivory.png` | Marfim `#F4EBDD`            | Fundos vinho escuro       |

Os arquivos são PNG RGBA de 940 × 460 px. Não adicionar sombras, gradientes, efeitos metálicos ou símbolos jurídicos.

## Referências originais

- `assets/references/adriana-reis-identidade-original.jpg`: identidade recebida da cliente, incluindo dados de contato.
- `assets/references/hero-referencia.jpg`: referência visual de composição da hero.

Os dados de contato da referência não fazem parte dos arquivos finais da logo.
